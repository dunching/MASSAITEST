## 4. 当前运动链

```text
Behavior / Objective
        ↓
Shared Flow / Macro Guidance
        ↓
Target Region（需要目标附近人口分布时）
        ↓
Local Predictive Interaction
        ↓
Movement Predict
        ↓
Particle / Environment Safety
        ↓
Facing / Finalize
```

Target Region 的正确理解：

> 目标附近的 Target-relative Polar Transport Field。

它使用 Radial Band + Angular Sector 形成 Polar Navigation Cells，通过 Demand Region、Population Deficit/Surplus、Transport Plan 与 Edge Quota 引导大量实体在目标周围展开。

它不是永久 Slot，也不是每个 Agent 固定绑定一个 Region owner。

当前补充的边界容量合同：

```text
Target 靠边/角落
→ Polar candidate 按真实 NavMesh / Environment 裁剪
→ 只保留 feasible Cell
→ feasible Cell 具有有限 deterministic capacity
→ Plan / Execution 管理 transient claim / admission
→ capacity 满后其余 Agent 进入 Overflow / CapacityHold
→ 不继续往已饱和 Target interior 挤
```

“Cell 可共享”不等于“Cell 无限共享”；finite capacity 也不等于永久 Agent Slot。

## 9. 修改代码时的硬规则

1. 同一模拟字段只允许一个 Production Writer。
2. Worker 不直接访问 UWorld / Actor / UObject / Mass View。
3. Task 只写 shard-local output，最终由 Owner 稳定 Merge。
4. GT 不把刚消费的 Worker 状态作为普通输入 echo 回 Worker。
5. 所有可失败验证发生在第一次写入前；之后进入 no-fail commit。
6. 旧生产结构被替代后必须物理删除，不保留 wrapper / fallback / stub。
7. Target / Particle 修复禁止按 AgentId、step、地图写特判。
8. finite Cell capacity / transient claim 不是永久 Slot；禁止引入 permanent Agent→Cell owner 系统。
9. Local Predictive / ORCA / Particle 负责安全，不得被用来代替 Target capacity admission。
10. legal Overflow 必须与真正 UnroutedFailure 区分。
11. 20 实体 PASS 不替代长窗口或 10k 门。
12. runner 返回 FAIL 时不得根据内部日志手工改报正式 PASS。
